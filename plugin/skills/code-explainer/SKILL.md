# 代码随读

调用 `open_reader`，root 使用当前项目的绝对路径，context 附带当前聊天中与阅读任务相关的简明背景摘要，例如项目用途、用户关注点和已核实的约定。只传解释需要的信息；路径已知时直接打开。

root 未知时可省略，用户在面板中点击“浏览文件夹”，使用磁盘、常用位置、最近项目或 Windows“系统选择…”打开目录，无需先手动输入路径。右上角“切换项目”支持再次选择。

选区请求由插件内部独立后台处理，结果直接进入浮窗。不要把每次选择转成聊天任务，不要创建侧栏聊天，不要调用旧版的 `get_explanation_context` 或 `publish_explanation` 流程。目录直接显示源码说明；用户可用“AI 完善用途”批量生成更具体的说明。

用户要求思维导图时，打开阅读器后指引点击工具栏“代码导图”。本地解析项目、目录、文件、类和函数，点击节点跳转实现；详情中可独立生成框架分层或函数总结。支持顶部固定、收起和面板内悬浮拖动，不能宣称桌面级置顶。Python/JS/TS 支持符号解析，其他语言只有文件结构；覆盖范围由面板显示。

导图可全屏阅读、选择 14/16/18 号字并缩放到 300%；默认 100%，不为适配整个项目自动缩小。全屏时 Esc 返回，点击源码节点会返回固定布局并定位。右上角“解释模型”可从真实后台目录选择或填写自定义模型 ID，沿用现有登录和提供方；不能保证自定义提供方支持目录中的每个模型。选择用于当前面板，保存为新面板默认；已有其他面板保留各自模型。无需把选模型操作发回聊天。

独立后台不能自动获得当前聊天的全部历史。打开时的 context 是显式传递的背景摘要；后续聊天不会自动同步。用户明确要求同步时，使用已有阅读器的 sessionId 调用 `update_reader_context`，context 写入更新后的完整摘要。也可在面板的“项目背景”中编辑。不要读取聊天数据库或声称已通读未提供的源码。

后台优先使用宿主提供的 Codex 程序及其现有登录；无宿主路径时使用本机 CLI。OpenAI 提供方优先用 gpt-6-luna，自定义提供方沿用已配置模型；可用 CODE_EXPLAINER_MODEL 覆盖。失败会在面板显示，不退回聊天生成解释。开发预览调用真实后台，不能替代实际桌面宿主的界面验证。
