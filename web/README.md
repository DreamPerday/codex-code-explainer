# 代码随读 · 独立网页版

本机启动后通过浏览器阅读项目，无需 Codex 插件。源码浏览、文件用途、选区解释、代码思维导图、全屏大字、函数源码跳转、项目背景和最近项目均可使用。

## 启动

需要 Node.js 20.3+（推荐 Node.js 22+）。Windows 双击同目录的 **启动网页版.cmd**，或在本目录运行：

```powershell
node server.mjs
```

打开终端显示的地址，默认 http://127.0.0.1:4318 。保持终端运行，Ctrl+C 停止服务。此目录已包含构建后的界面和后台，运行时无需 `npm install`，API 方式不需要安装或登录 Codex。

```powershell
node server.mjs --open
node server.mjs --port 4319
node server.mjs --root "E:\projects\my-app"
```

## 选择项目与配置模型

1. 首页“浏览文件夹”可使用磁盘、常用位置、最近项目和逐级导航；Windows 支持系统文件夹窗口。选择的是运行后台这台电脑上的目录。
2. 右上角“模型与 API”选择 **API 接口**，填写提供方的 API 基础地址（一般以 `/v1` 结尾）及 Key。支持 OpenAI 兼容的 Chat Completions 接口，不支持 Anthropic 原生 Messages 等其他协议。
3. 点击“读取模型列表”，选择或直接填写模型 ID。“测试连接”会发起一次简短模型请求；保存设置后用于选区、文件用途和导图总结。
4. 本地免鉴权服务可留空 Key。流式输出可关闭，以适配只支持普通 JSON 响应的服务。模型应能遵循 JSON 输出要求。
5. 也可选择 **本机 Codex**，沿用本机现有登录及模型提供方。模型留空时自动选择，也可从目录选择或填写提供方支持的模型 ID。

Key 不会从设置接口返回，不写入网页本地存储。默认只保留在后台进程内；勾选“记住密钥”后保存到本机偏好文件。Windows 使用当前账户的 DPAPI 加密；其他系统使用仅当前用户可读的配置文件权限。更换提供方域名时不自动复用旧 Key，需重新填写。请勿把自己的偏好文件放进分享包。

网页设置位于 `~/.codex/code-explainer-web/`，可用 `CODE_EXPLAINER_WEB_STATE_DIR` 指定其他目录。端口也可用 `CODE_EXPLAINER_WEB_PORT` 设置。设置、最近项目与 Codex 插件分开保存。每个浏览器标签页各自选择项目；同一标签页刷新可恢复尚未过期的会话。模型连接设置共享，其他已打开页面约 5 秒内更新并取消旧分析。

## 阅读

打开文件后选中代码，解释出现在浮窗；可关闭自动解释后按 Ctrl+Enter 手动触发。文件名旁先显示注释或结构提示，“AI 完善用途”根据源码补全说明。

点击“代码导图”浏览项目、文件、类、函数和方法。支持顶部固定、面板内悬浮、全屏、14/16/18 号字和 50%–300% 缩放；点击函数定位源码。Python、JavaScript、TypeScript 支持符号解析；其他语言显示文件结构。AI 总结按需触发。

“项目背景”可填写阅读目标。独立网页没有 Codex 聊天上下文；解释依据已提供的背景、选区、相关源码和文档。项目结构由本地解析生成，不需要调用模型。解释会把所需源码发送给你配置的模型提供方。

## 运行范围

后台仅监听 `127.0.0.1`，用于本机单人阅读。浏览器只访问本机后台，由后台调用模型；API Key 不通过 URL、模型列表或错误响应返回。读文件沿用项目边界、敏感文件排除和大小限制。

此版本没有公网用户登录、多人隔离或代码上传服务，不能直接作为公网网站部署。`/health`、`/ready` 可检查服务状态。端口占用时通过 `--port` 更换；API 报错可在设置中测试地址、Key 和模型。
